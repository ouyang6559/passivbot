# 五种行情状态参数集(每币 x 5 状态,共 25 套)

> 生成:`backtests/regime_analysis_2026-10`(分析脚本与中间数据同目录)。
> 数据源:Binance USDT-M 合约公开 1h K 线(2021-01-01 ~ 2026-10-01,无鉴权行情数据)。
> 基准配置:`configs/examples/BTC_ETH_XRP_SOL_ADA_long.json`(v8.4.0,trailing_martingale,仅多头)。
>
> **这些参数是基于历史波动统计的刻度起点,不是优化器输出。**
> 建议把它们作为起始点,用仓库优化器对各币再精调
>(把 `optimize.bounds` 收窄到本文件数值 ±20% 左右)。

## 1. 行情状态定义(每币独立标定)

| 状态 | 判定规则(按优先级,基于每币自身分布的分位数) |
|---|---|
| 极端波动 | 日实现波动率 ≥ P98,或单日涨跌幅绝对值 ≥ P98(崩盘/插针日) |
| 熊市下跌 | 价格 < EMA90,且 30 日收益处于最差 P15 且为负(或距 90 日高点回撤 > 20%) |
| 强趋势(上行) | 30 日收益处于最好 P15 且 > +8%,价格 ≥ EMA90 |
| 低波动震荡 | 日实现波动率 ≤ P30,且 14 日漂移小(≤ P40 的 \|漂移\|) |
| 正常震荡 | 其余情况 |

## 2. 刻度原理(每条规则对应参数)

- **间距比例 S**:状态内中位日振幅 ÷ 五币正常震荡中位振幅(XRP 5.51%)。
  入场/止盈网格距离与已实现振幅近似线性相关(`docs/config.bot.md` 中阈值公式),故按 S 缩放,
  再叠加状态倾向系数(熊市/极端再放宽 15%/25% 防接刀)。
- **首次入场量**:∝ 1/√S —— 波动越大,同等 WEL 切成更多阶梯;熊市/极端再乘 0.65/0.50。
- **补仓系数 double_down_factor**:马丁格尔增速,防御状态调低(0.74 → 0.62 → 0.55)。
- **止盈距离**:强趋势 ×1.45 让利润奔跑;熊市/极端 ×0.85/0.80 快速止盈离场。
- **追踪模式**:仅强趋势启用(retracement_base_pct > 0),先突破后回踩确认,顺趋势接回调;
  其余状态保持网格(与基准配置及 scenarios 中 pure_grid 一致)。
- **波动率 EMA 跨度**:熊市/极端缩短(更快反应),低波动拉长(滤噪)。
- **风险敞口**:we_excess_allowance(借槽位额度)防御状态下调;entry_cooldown 熊市 5 分钟、极端 15 分钟,
  崩盘中暂停连续补仓。
- **解套**:防御状态提前触发(threshold ↓、ema_dist 更负)、单次量加大、亏损预算收紧。
- **选币**:熊市/极端加入 0.25 的 ema_readiness 权重(优先选已靠近入场带、不再追高动量的币),
  并缩短波动率 EMA 跨度。

## 5. 用法

```json
"coin_overrides": {
    "SOL": { "bot": { "long": <本文件 4.4 表中对应状态的整列参数> } },
    ...
}
```

- 把对应币当前所处状态的整列参数放进 `coin_overrides.<coin>.bot.long`,其余 bot 参数沿用基准配置;
  或者手动把整套 `bot.long` 换成对应状态的参数(临时切换用 `forced_mode_long` 更直接)。
- 实时判断当前状态:用 `analyze_regimes.py` 中同样的指标(日实现波动率分位、30 日收益、EMA90 位置)
  对最近 30~90 天滚动计算即可;图表 `charts/regimes_<COIN>.png` 可对照历史。
- 数值可能超出基准配置的 optimize.bounds 搜索范围(基准对所有币共用一套边界);
  若要按币优化,请把 bounds 放宽到本文件数值附近。
