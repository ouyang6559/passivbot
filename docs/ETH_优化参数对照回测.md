## 3. 关键发现

1. **纯空头 5/5 全部存活**(基线 4/5 清算)。HSL 红档熔断把每次"-95% 清算"
   替换为一次约 -10% 的受控退出,这正是机制分析(《空头与双向爆仓机制分析.md》第 4 节)
   预测的第一优先修复。
2. **剩余清算全部集中在 both 模式**(4 个配置、5 次,全部发生在 2025-07~08 的
   剧烈震荡段)。其中 normal_osc both 2025-07 的解剖显示:HSL 触发 3 次全部在多头腿
   (熔断累计亏损 -42,784,红灯时间占比 36.7%),**空头腿 0 触发**——
   空头腿的"成本暴露顶格 + 缓慢失血"不在 HSL 红色信号的捕捉范围内;
   最后一周权益 45,600 → 5,000,恰为 8 个连续红档日(冷却 1 天 → 次日重启 → 再熔断)。
   **HSL 防得住"跳崖",防不住"阴跌 + 反复熔断"。**
3. **代价:收益中枢整体下移**。15 个配置中 14 个期末复合资金低于 1x
   (最高 strong_trend long 1.01x)。HSL -10% 熔断把 2022 年多头的大回撤
   切成受控亏损(如 normal long 2022:-57% → -20%),但牛市利润同样被熔断
   与 10 分钟入场冷却切碎。**这是用收益换生存的保守组合,不是免费午餐。**
4. extreme_vol 档三方向几乎无变化(0.94~0.97x):其自身暴露已极低,
   HSL 几乎不触发,验证了"防御档不需要熔断"的判断。
5. both 模式再次垫底(0.00x~0.06x):双腿同时熔断的成本叠加,
   且空头腿的失血通道不受 HSL 保护——静态双向在任何参数组合下都不成立。

## 4. 下一轮(降杠杆前)的待办

1. 复盘 HSL 信号口径:2025-07 案例中空头腿未触发红档,确认
   `hsl_signal_mode`(unified/pside)在回测中的实际语义,考虑给空头腿单独的
   保守阈值(如 0.05)。
2. `cooldown_minutes_after_red` 从 1 天延长(如 7 天)或红档后强制
   `forced_mode=t`(只平不开)一个窗口,打断"每日 -10%"的连环熔断。
3. 完成上述两项后,再进入降杠杆轮(10x → 3~5x)与逐仓评估。
